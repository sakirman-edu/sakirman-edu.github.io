# Dr. Sakirman Academic Website

Static GitHub Pages website with a dark astronomy-inspired academic portfolio design.

## Files
- index.html
- research.html
- publications.html
- teaching.html
- cv.html
- assets/style.css
- assets/main.js

## GitHub Pages
Use **Settings → Pages → Deploy from a branch → main/master → /(root)**.
This package is plain HTML/CSS/JS and does not require Jekyll or GitHub Actions.
